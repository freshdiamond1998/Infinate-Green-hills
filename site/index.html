Controls

Desktop: WASD / arrows move, Shift runs, E uses/interacts, I or Tab inventory, C crafting, Q drops/deletes selected item, mouse wheel zoom.

Creative: select a build piece on the hotbar, then click/tap clear ground to place it. Dropping an item deletes it.

Mobile: joystick moves, RUN sprints, USE interacts, INV opens inventory, CRAFT opens crafting, zoom slider changes view.
